# V7-09 — Plagát a zin

Vetva: `v7-09-plagat` · výstup: `work/v7/vystup/09/` · médiá: `public/v7/09/`

**Idea.** Maximalistický risograf zin: obrie typografia, vrstvy papiera, pásky, pečiatky, nálepky. Hlasný neobrutalizmus naplno.

**Layout.** Rozbitá mriežka s prekrývaním: bloky sú listy papiera natočené pod rôznym uhlom, prelepené páskou. Obrie XVADUR cez dve obrazovky. Tézy ako manifest cez celú šírku.

**Komponenty (minimum, smieš pridať).** sticker, shapes (veľa), layered-card, badge, marquee, stat-card, sparkline, accordion, carousel, date-picker, time-picker, sonner. Fancy (text), React Bits (text a kurzor), Magic UI (marquee, highlight).

**Pohyb.** CSS `animation-timeline: view()` a `scroll()`: paralaxa vrstiev papiera, listy sa pri scrollovaní dotáčajú na miesto. Podpis: pečiatka OVERENÉ udrie na blok vitálnych funkcií, keď sa čísla načítajú.

**Higgsfield.** 8 risograf obrazov a koláží (nemocnica, papiere, EKG, ruky, Adam cez Soul ID ako čiernobiela koláž), 3 papierové textúry (Seedream), 1 slučka 3 s (tlačiarenský valec alebo papier letiaci cez záber).

**Proti konkurencii.** Konkurencia je uhladená a šablónová; zin je najhlasnejší a najosobnejší tvar webu. Presne štvrtá vec z laťky: hlasný neobrutalizmus.

Iný než ostatné varianty: nepreberaj layout ani podpisový pohyb z iných konceptov v `work/v7/koncepty/`.
