## Ostrovy — konvencie
- `client:visible` default, `client:idle` pre malé CTA (wizard), `client:media="(max-width: 1023px)"` pre mobil-only, `client:only="react"` pre všetko, čo siaha na `window` pri importe (GSAP pluginy, matter-js, shadery, Lenis, Rive). Motion `initial` musí byť SSR-stabilné; žiadny `window` mimo `useEffect`.
- Lenis inštancia: `window.__lenis` (GSAP ScrollTrigger: `lenis.on('scroll', ScrollTrigger.update)`); modálne/skrolovateľné prvky `data-lenis-prevent`. Vlastný kurzor: prvok s `data-cursor="vstup"` zmení X na štítok VSTÚP (iná hodnota = jej text); kurzor beží len ≥ 1024 px s hoverom, bez reduced motion; `html.has-cursor` skrýva systémový kurzor. ⌘K: `data-commandk` alebo `CustomEvent('xvadur:commandk')`. Toast: `import { toast } from 'sonner'` (Toaster je v Base pri `islands` full/lite).
- Ikony: `@phosphor-icons/react` s príponou `Icon` (`ArrowRightIcon`, `weight="bold"`); v .astro bez client direktívy sa vykreslia staticky. Radix: `import { Dialog } from 'radix-ui'`. `cn()` z `@/lib/utils`.
- Rozpočet JS (gz, zmerané 19. 9.): `islands="full"` ≈ 98 kB na desktope (React runtime 65 + ClientRouter 5 + Smooth 6 + CommandK 6 + radix/ikony 22 + Toaster) + CursorX 42 lazy len na desktope; mobil namiesto kurzora Drawer +10. `islands="lite"` ≈ 75 kB desktop / ≈ 105 kB mobil (Drawer + radix). Doc 10 chce domov ≤ 180 kB, podstránky ≤ 70 kB → podstránky `islands="lite"`, články `"none"`; na domove má hero/GSAP/hry ostrov k dispozícii ≈ 40 kB. Nič ťažké (matter-js, shadery) mimo `client:visible`/desktop; matter-js a shadery len `client:only` + `matchMedia` guard.
