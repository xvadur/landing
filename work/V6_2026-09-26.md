## Čo môžeš urobiť len ty
1. **Pozrieť a povedať slovo.** `git fetch origin claude/determined-goldberg-xy19as && git checkout claude/determined-goldberg-xy19as && npm install && npm run build && python3 -m http.server 4190 -d dist/client` → http://127.0.0.1:4190/.
2. **Odber**: v Cloudflare Workeri `xvadur-com` nastaviť `ODBER_WEBHOOK_URL` (n8n Webhook node, dostane JSON
   `{ typ, web, email, zdroj, cas }`) alebo `RESEND_API_KEY` (+ `RESEND_AUDIENCE_ID`). Bez toho formulár posiela na mailto.
3. **Lákadlo za e-mail** (prompt / návod / video): `src/data/ponuka.ts` → `ODBER.magnet = { nazov, popis, url }`.
   Kým je prázdne, sľubuje sa len existujúci text.
4. **Overiť 200** pre jakubolsa.sk a picung.xvadur.com pred deployom (tu bez siete): `curl -sIL -o /dev/null -w '%{http_code}' https://jakubolsa.sk`.
   Ak niektorý nebeží, v `src/data/projekty.ts` daj `url: null` — karta ostane, odkaz zmizne.
5. **Ratifikovať jedným slovom**: čísla z účteniek namiesto fakty.ts (25 tabuliek, 1 518 vlákien, 48 skillov) · KVÍZ v nav
   namiesto SKÓRE WEBU · „Čo treba opraviť“ verejne na kartách · doména klienta bez mena.
6. **Deploy** (slovo „deploy“): merge do `main`, `npm run build && npx wrangler deploy -c dist/server/wrangler.json`.
   Po nasadení: WAF rate limit aj na `/api/odber` (napr. 10 req/min/IP).
