## (d) Odchýlky od spec 05 / doc 10 (s dôvodom)
- **Text na hot = ink, nie paper** — doc 10 farbu textu nepredpisuje; paper na hot má 3,2 : 1 (pod AA), ink 5,4 : 1. Jedným sedom vratné.
- **Mobilná navigácia = natívny `<dialog>`**, nie vaul Drawer (doc 10 §3) — 92 kB gz React + vaul na každej stránke vrátane článkov (doc 10: články 0 kB).
- **Hero motto max ≈ 160 px** (doc 10 §4: 160–240) — „WE ARE USELESS.“ v jednom riadku sa do 1200 px kontajnera väčšie nezmestí; mobil 64 px, 3 riadky.
- **Domov nad 180 kB na desktope** (254 kB) — lazy efekty, ktoré doc 10 §4 výslovne pýta (GSAP hero + dvere, shader, ImageTrail, matter). Mobil 147 kB, reduced 147 kB.
- **Podstránky nad 70 kB** tam, kde je React ostrov (kvíz, skóre, hry, škrtací test, konzultácia): základ lite = React runtime 63 + sonner 9 + ClientRouter 5. Bez Reactu (makléri, texty) 6–12 kB.
- **MorphingDialog → Radix Dialog, Terminal → CSS log, StickerPeel → utilita `sticker`, TransitionPanel/Stepper/NumberFlow v kvíze → CSS/Intl/vlastný indikátor, Magic UI ScrollProgress → CSS `animation-timeline`** — rozpočet JS a prístupnosť; vizuál ostáva.
- **Zdieľacia karta škrtacieho testu cez Canvas 2D**, nie satori (zadanie noci).
- **Skóre: „rezervácia“ platí aj bez widgetu**, ak web ponúka termín (kotva 15/416 je o ponuke, nie o nástroji).
- **Pack 04 na /konzultacia/**: OpenClaw veta vynechaná (interný vypnutý runtime), interný pokyn o prílohách prepísaný do 1. osoby; ukážka hodnoty/ceny/„prečo nie kurz“ nie sú (spec 05 §3 ich nepýta).
- **Hry 2 a 3 bez popisu** (spec dáva len názvy), nálepka „V stavbe“ je CSS utilita, nie StickerPeel.
- **`/hry/skrtaci-test/` islands lite** (kontrakt: hry = full) — stránka s formulárom, Lenis a kurzor nič nepridajú.
- **Kvíz: body, pásma 40/70, strop 39 bez vlastníka** = kalibrácia agenta; na webe je vypísaný len princíp „body / maximum × 100“.
- **Deň 8 „[booking link]“ → `/konzultacia/?z=plan`** (zadanie); úvodzovky packu → slovenské typografické.
