# xvadur.com

Verejný web Adama Rudavského / XVADUR: hero, kto som, čo som postavil, hry, kvíz, texty, makléri, konzultácia. Astro 7 + React ostrovy + Tailwind 4, Cloudflare.

## Lokálne

```bash
npm install
npm run dev
```

## Overenie

```bash
npm run check
npm run build   # → dist/client/
npm test
```

Vetva `v4` je rozpracovaná verzia (nenasadená). Produkčná doména beží na Cloudflare projekte `landing` (`xvadur.com`, `www.xvadur.com`). Starý Vite web je v `legacy/`.
